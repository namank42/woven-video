# The 105 questions flagged for evidence

Extracted September 8, 2026 from the existing page map. This preserves the original flags; it is not a finding that Woven lacks 105 capabilities.

The flags mix three things: unverified product behavior, missing examples or comparative research, and general advice that was caught by a page-level hold. The last category does not need to wait for a feature test to be answered accurately. For example, Q237 is a conceptual explanation; Q359 can explain using external retention data without claiming an analytics integration; Q432 and Q433 need careful examples rather than a special product capability. Q211 was assigned to the clipping page too broadly: audio continuity belongs with editing/audio guidance. These are review notes, not silent changes to the original map.
