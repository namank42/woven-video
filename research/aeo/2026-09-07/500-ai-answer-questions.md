# 500 questions for Woven's AI-answer research

Created September 7, 2026.

These are brainstormed questions that prospective users might ask AI assistants about video creation, editing, and related jobs. They are hypotheses, not measured searches or verified AI prompt volumes. The earlier DataForSEO research informed the topic selection; no new API requests were made for this brainstorm.

All 500 questions omit Woven's name so they can be used to test unaided product discovery. Competitor names appear where a real buyer might ask for an alternative or comparison. Questions are not claims that Woven supports a capability. Some deliberately explore adjacent needs, limitations, and reasons to choose another product.

## How to use this bank

- Start with a small, balanced sample of questions. Do not treat 500 equally weighted prompts as a representative demand survey.
- Run each question in a fresh conversation with the same search settings. Record date, engine/model, region, exact prompt, whether web search ran, recommended products, Woven mentions, cited URLs, and factual errors.
- Measure a product recommendation separately from a passing mention or a citation. An answer may legitimately recommend no software.
- Repeat sampled questions to observe variability. Do not interpret a single answer as a stable rank.
- Group overlapping questions into a shared intent before planning content. These are not 500 proposed landing pages.
- Validate Woven's actual capabilities before prioritizing adjacent areas such as automatic clipping, voice cloning, dubbing, collaboration, and local processing.
- Keep competitor comparisons neutral. Never add Woven's name merely to improve the measured recommendation rate.
